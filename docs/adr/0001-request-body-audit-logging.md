# 请求体原文不脱敏存入使用日志

以审计（长期留档所有输入）为首要目的，relay 客户端原始请求体按 64KiB（可配置）截断后原文存入 `logs` 表新列 `request_body`，不做字段脱敏；仅管理员可见（列表查询排除该列，经独立懒加载端点取用），开关默认关闭。不脱敏是因为脱敏规则永远追不上真实内容多样性、只会给人虚假安全感，泄露面靠截断、管理员可见性与手动清理来约束。前置失败（无可用渠道等）在开关开启时补记错误日志行，保证审计无盲区，且不依赖 `ERROR_LOG_ENABLED`。

**Considered Options**（均被否）: 字段脱敏（保真度受损、虚假安全感）；Filebeat→ES 观测链路（放弃 console 权限/筛选体系，另养一套组件）；独立 request_bodies 表（生命周期与使用日志分叉，多一套迁移与清理）。
